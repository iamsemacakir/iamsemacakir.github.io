Mail Assistant — Privacy Policy

Last updated: 21 November 2026

Mail Assistant is a personal automation built and used only by the owner of this website, Sema Cakir, to manage four personal Gmail accounts. It is not offered to the public, and no one else signs in to it.

Data the app accesses

With the account owner's permission, the app uses the Gmail API to read the sender, subject and text of messages received in the last 24 hours, and the account's list of Gmail labels.

How the data is used

  • The sender, subject and first 3,000 characters of each new message are sent to the Anthropic Claude API, which assigns a category (for example Important, Interview or Subscription) and writes a one-sentence summary.
  • The app adds a Gmail label for that category. For messages classified as newsletters or advertising, it calls the sender's standard unsubscribe link and moves the message to Trash.
  • Once a day, the sender, subject and Gmail snippet of the last day's messages are sent to the Claude API to write a short digest.
  • Summaries of important messages and the daily digest are delivered to the owner's own devices through the ntfy.sh notification service.

Storage and sharing

The app runs on GitHub Actions and does not keep email content in any database or file. The OAuth tokens it needs are stored as encrypted secrets in a private GitHub repository. Google user data is never sold, used for advertising, or shared with anyone other than the two services named above, which process it only to provide these functions.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be withdrawn at any time under Google Account → Third-party apps & services.
